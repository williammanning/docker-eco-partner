# Docker Ecosystem — Reference Architecture

Interactive reference architecture diagrams for the Docker ecosystem.

## Files

- `index.html` — Partner Opportunity Map (dark theme, interactive)
- `customers.html` — Customer Ecosystem Map

## Hosting on GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select `main` branch and `/ (root)` folder
4. Click **Save**
5. Your pages will be live at:
   - `https://<your-username>.github.io/<repo-name>/` (partner map)
   - `https://<your-username>.github.io/<repo-name>/customers.html` (customer map)

## Embedding in Notion

Once GitHub Pages is live, in your Notion page:
1. Type `/embed`
2. Paste the GitHub Pages URL
3. Resize the embed block to fit
